**A runnable failure simulator, not just a CRUD application.** Inject duplicate callbacks, transient failures and poison events; inspect a live retry timeline and replay dead-letter events. Explore the transaction boundary behind one event identity and one demo ledger entry.

- Conditional claims, bounded retries and durable attempt history
- Integration tests covering concurrency, signature validation and transactional rollback
- Original portfolio code developed with AI assistance; no employer code or real payment data
